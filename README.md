# MP3 乱码标签清理工具

把 MP3 里显示为乱码的 ID3 标签**删掉**，让播放器回退去显示文件名。

不重新解码、不猜原始编码——只做「删除」这一件事，所以不可能猜错。

## 运行

```bat
双击 run.bat
```
或者：

```bat
python mp3_tag_cleaner.py
```

程序只有图形界面，没有命令行参数；双击后直接出窗口，所有操作都在界面里完成。
依赖只有一个：`pip install mutagen`（本机已装 1.47.0）。

## 界面用法

1. **添加文件夹** —— 递归找所有 `.mp3`，扫完之后**自动把有乱码的文件筛出来并全部选中**。
   列表里就只剩这些乱码文件，正常的都被隐藏了，直接点「清除全部标签」即可。
   状态栏会写清楚筛出了几个。想切回完整列表，取消工具栏的 **「只看乱码文件」** 勾选。
2. **添加文件** —— 手动挑几个，不做筛选。
3. 列表每行的状态是 `乱码 N 处` / `正常` / `无标签`。点某个文件，下面的
   「标签明细」会把每个标签帧列出来，乱码的标红。
4. 点按钮处理。**不勾选任何行 = 只作用于列表里当前可见的文件**（不是全部文件）——
   所以筛选状态下误点按钮，不会碰到被隐藏的正常文件。

| 按钮 | 作用 |
|---|---|
| **清除全部标签** | 删掉整个 ID3v2 + ID3v1。最彻底，播放器一定显示文件名。 |
| **仅删除乱码标签** | 只删判定为乱码的字段，正常的标签（比如专辑、封面）保留。 |
| **预览结果** | 先看看会处理几个文件，不写入。 |

勾选项：

- **保留封面图片** —— 清除全部标签时，把内嵌封面单独留下来。
- **同时清除 ID3v1** —— 老播放器读的就是这个标签，建议保留勾选。
- **用文件名重建标题** —— 如果你想让播放器显示得好看点，可以顺手把标题写成文件名。

> **写入是直接改原文件，不做备份，无法撤销。** 不放心就先自己复制一份，
> 或者先点「预览结果」看一眼会删掉什么。

## 乱码是怎么判定的

国内 MP3 的中文标签乱码，绝大多数是**字节被用错编码读了**：
GBK 的字节被当成 Latin-1，屏幕上就成了 `Ò¹Çú` 这种样子。

所以判定很直接——看一段文本里「正常标题几乎不会出现」的字符占比：

- 出现 `�`（解码时就已经坏掉的替换字符）→ 乱码
- 出现 `Œ š Ž ‹ › ƒ ˜ † ‡ ‰` 这类 cp1252 独有字符 → 乱码
- `À-ÿ` 区间字符占比 ≥ 30%，或 `¡-ÿ` 区间占比 ≥ 45% → 乱码

`Café`、`Motörhead` 这类正常带音标的标题不会被误判。

判断不准也不要紧——**先点「预览结果」看一眼，明细里乱码的都标红了**，
确认没问题再动手。

## 实现上的两个坑（已处理）

- **音频数据一个字节都不能动。** 删 ID3v2 是在字节层面把开头那一块切掉
  （读 10 字节头算出 syncsafe 长度，含 footer 标志位），末尾的 ID3v1 直接
  `truncate` 掉 128 字节。测试里逐字节比对过清理前后的音频。
- **mutagen 的 `keys()` 返回的不是纯帧 ID。** 对注释、封面、自定义帧它给的是
  哈希键 `COMM::eng`、`APIC:cover`、`TXXX:xxx`。直接拿它去比对帧 ID 集合会
  永远匹配不上，导致这些帧被漏掉——必须先 `split(":", 1)[0]`。
